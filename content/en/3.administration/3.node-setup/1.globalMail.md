---
description: Sends mails using an Administrator configured Mailserver.
---

Administrators can configure this Node globally to allow Instance Users to send mails without having to use a low-level mail Node.

Be aware: without proper external ratelimiting, users may spam your mailserver and get you blocked from mail providers!
Only configure if you are 100% sure you won't face any abuse issues or can deal with it!

Currently, only the SMTP protocol is supported. Additional custom providers will be added based on demand.

## Configuration
```yml
globalMail:
  type: Smtp
  host: mail.example.com
  port: 25
  startTls: true
  username: myusername
  password: mypassword
  from: snoty@example.com
```
